# Unity Netcode Relay Setup Guide - Internet Multiplayer

This guide explains how to set up your project for internet play using Unity Relay.

## What Changed

- **Before**: Local LAN only - both players connect to same IP address
- **After**: Internet play - players join via relay join codes (no port forwarding needed)

## Setup Steps

### 1. Unity Cloud Project Setup

1. **Open Unity Hub**
2. **Create/Connect Cloud Project**:
   - Go to your project in Unity Hub
   - Click on the project name → **Link** (if not linked)
   - Create a new Cloud project or select existing one
3. **Note the Project ID** - you'll need this later

### 2. Unity Services Configuration

1. **In Editor: Window > Cloud Save > Authentication**
   - Verify Authentication is enabled
   - You should see "Anonymous" sign-in is available

2. **In Editor: Window > Cloud Save > Relay**
   - Should show Relay service is available

3. **If services aren't showing up**:
   - Go to **Window > TextMesh Pro > Import TMP Essentials** (sometimes needed)
   - Try **Services > All Services**
   - Link your Cloud project from there

### 4. How It Works Now

**Host Starting Game:**
```
Host clicks "Host Game"
→ RelayManager initializes Unity Services
→ Authenticates anonymously
→ Allocates Relay session
→ Gets Relay join code (e.g., "A1B2C3")
→ NetworkManager starts with Relay configured
→ Join code displayed to player
```

**Client Joining:**
```
Client enters join code: "A1B2C3"
→ RelayManager initializes Unity Services
→ Authenticates anonymously
→ Joins Relay session with code
→ NetworkManager starts with Relay configured
→ Connected to host via Relay
```

### 5. Testing Internet Play

**Option A: Same Machine (Easiest Testing)**
- Run game twice: one as Host, one as Client
- Host gives join code to Client
- They connect via Relay (works like LAN but uses internet backend)

**Option B: Different Machines on Same Network (LAN)**
- Build game as standalone executable
- Run on two computers on same network
- Use join code to connect
- Note: Still goes through Relay servers (not direct P2P)

**Option C: Different Machines on Different Networks (True Internet)**
- Build game as standalone executable
- Run on two different networks / different locations
- Use join code to connect
- Everything routes through Unity Relay servers

### 6. Troubleshooting

**Error: "Services not initialized"**
- Solution: Make sure Cloud project is linked in Unity Editor
- Check: Services > All Services > see if they're available

**Error: "Failed to allocate Relay"**
- Solution: Check internet connection
- Check: Cloud project is linked and active
- Check: Unity project is linked to Cloud project

**Error: "Failed to join Relay with code"**
- Solution: Make sure code is correct (case-sensitive)
- Solution: Make sure host is still running (allocation expires after ~1 hour)
- Solution: Check internet connection on both machines

**Can't see others' players**
- Solution: Wait a few seconds after joining
- Solution: Check console for errors
- Solution: Try restarting game

### 7. Important Notes

**Relay Service:**
- Free tier available (check Unity pricing)
- Handles NAT traversal automatically
- Players don't see each others' IPs (privacy!)
- Works cross-platform (Mac ↔ Windows, etc.)

**Join Codes:**
- Now generated by Unity Relay (not random strings)
- Format: 6 alphanumeric characters
- Valid until host disconnects or 1 hour passes
- Each session gets unique code

**Network Traffic:**
- Routes through Unity Relay servers
- Not peer-to-peer (different from some services)
- More stable for players with restrictive firewalls
